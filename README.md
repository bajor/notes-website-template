# Notes Website Template

Create a repository from this template, then add one supported one-page Apple Freeform PDF. The workflow publishes it as a GitHub Pages website.

1. In the new repository, open **Settings > Pages** and set **Source** to **GitHub Actions**.
2. Commit exactly one PDF anywhere in the repository.
3. Open a pull request to validate the generated site, then merge it into `main` to publish.

The website title is the repository name. Rename the repository before adding the PDF if you want a different title.

See [Notes Website Factory](https://github.com/bajor/notes-website-factory-workflow) for supported PDFs, generated artifacts, and workflow details.
